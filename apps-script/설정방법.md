# 방명록 저장용 구글 시트 만들기 (5분)

1. https://sheets.new 에서 새 구글 시트를 만들고, 이름을 `청첩장 방명록`으로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본으로 들어 있는 코드를 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여넣은 뒤 💾 저장합니다.
4. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 톱니바퀴 ⚙️ → **웹 앱** 선택
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** 클릭
5. 권한 요청 창이 뜨면 본인 구글 계정을 고르고 **허용**합니다.
   ("Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (안전하지 않음)으로 이동**을 누르세요. 내가 만든 스크립트라 괜찮아요.)
6. 마지막에 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`)을 복사해서 Claude에게 알려주세요.

## 관리하기

- 첫 글이 등록되면 시트에 `방명록` 탭이 자동으로 생깁니다.
- 지우고 싶은 방명록은 시트에서 그 줄을 삭제하면 청첩장에서도 바로 사라져요.
- 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 해야 반영돼요. (URL은 그대로 유지)
